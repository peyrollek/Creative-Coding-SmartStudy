# Creative-Coding-SmartStudy
Creative Coding Project SEM1 A2

About SmartStudy

SmartStudy is a university assessment planner created using Python. The purpose of this project is to help students organise their assessments, manage deadlines and prioritise their academic workload. 

Features
- Allows students to enter their name and university course.
- Allows users to add multiple assessments and deadlines.
- Calculates how many days remain before each assessment is due.
- Organises assessments in deadline order.
- Identifies the assessment with the closest deadline.
- Displays warnings for urgent and overdue assessments.
- Saves assessment information using JSON.

Technologies
- Python
- Visual Studio Code
- JSON
- GitHub

How to Run the Program
1) Download the smartstudy.py file.
2) Open it using Visual Studio Code.
3) Make sure Python 3 is installed.
4) Run the program.
5) Follow the instructions in the terminal to enter assessment and due dates.

Future improvements

In the future, SmartStudy could include a graphical user interface, automatic deadline notifications and a calendar to help students manage their assessments more effectively.
